Radar images and `map-data.json` in this directory were downloaded from the
[awpy-data release 2000938](https://github.com/pnxenopoulos/awpy-data/releases/tag/2000938)
for local development of CS Tracker's 2D demo analyzer.

The extraction scripts are MIT licensed. The radar images and overview data
originate from Counter-Strike 2 and remain Valve assets. Review the source's
[licensing notes](https://github.com/pnxenopoulos/awpy-data#licensing) before
including these files in any public build or GitHub update.
