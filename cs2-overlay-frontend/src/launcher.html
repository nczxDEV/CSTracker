Software Update New

CS Tracker checks a public GitHub Releases feed for newer versions - no personal data is sent with the check. Updates are cryptographically signed; an update is only ever installed after its signature is verified.

CS2's official Game State Integration (GSI) feature can send your live match state to CS Tracker automatically - no more manually typing in a 10-player roster. This only ever sends name/team/kill-death-assist/score data - CS Tracker never requests or processes other players' position or visibility data (see the backend's GSI compliance notes).

Player Tracking FACEIT · Discord

Track any FACEIT player by nickname - not necessarily someone you're playing with. CS Tracker checks their match history every few minutes and sends a Discord alert (see Webhook URL above) whenever their next match finishes, with their personal K/D and stats for that match.

FACEIT only - Valve doesn't publish a public API for CS2 Premier/Casual match history for arbitrary players, so this can't track a Steam-only/Premier player unless they happen to be in your own live match (see "My Match History" on the Player Summary tab for that case).

Time-Based Performance GSI-free

Enter a FACEIT nickname to see a breakdown of their win rate by hour of day and day of week, built purely from their FACEIT match history (up to the last 100 matches) - works for any player, no GSI connection needed. Use it to spot which hours are actually worth queuing ranked in.

Dodge or Play FACEIT Matchroom

Paste a FACEIT matchroom link (same one as the Overview tab) to screen both squads for suspected smurf accounts and players currently on tilt, and get a PLAY/DODGE recommendation with an estimated win probability. Uses only public FACEIT stats already visible on each player's profile - a probabilistic indicator, not a fact-checked accusation.
